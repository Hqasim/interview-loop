# Screenshots

Drop screenshots here using the exact filenames below — the root `README.md` already references
them by these paths, so no other file needs to change once they're added.

| Filename | What to capture |
|---|---|
| `home.png` | The home page (`/`) — the prompt catalog grid. |
| `prompt-workspace.png` | A prompt open (`/prompts/[id]`) with some code in the editor, before submitting. |
| `feedback.png` | The same workspace right after submitting — the AI feedback panel visible below the editor. |
| `history.png` | The history list (`/history`) with at least one attempt in it. |
| `attempt-detail.png` | An attempt's detail view (`/history/[id]`) — the read-only code + its feedback. |

**Tips for a polished result:**
- Capture at a reasonably wide viewport (~1440px) so the layout looks like a real desktop session, not a squeezed mobile crop.
- PNG, not JPEG — the UI is mostly flat dark colors and text, which PNG compresses cleanly with no artifacting.
- Crop out browser chrome (address bar, bookmarks) — just the page content.
- Use the [live demo](https://master.d9ozh3inwy25s.amplifyapp.com) with real, sensible-looking data (a solved prompt with good feedback, a history list with a few varied attempts) rather than an empty/placeholder state.
